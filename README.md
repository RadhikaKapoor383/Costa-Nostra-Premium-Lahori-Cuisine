# 🍽️ Costa Nostra — Premium Lahori Cuisine

> *Where Lahore's heritage meets luxury dining.*

A fully responsive, multi-page restaurant website built with pure **HTML**, **CSS**, and **vanilla JavaScript** — no frameworks, no dependencies. Features online ordering, table reservations, user authentication, a favourites system, and a personal dashboard.

---

## Pages Overview

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero section, featured dishes, call-to-action |
| Menu | `menu.html` | Full menu with cart & favourites |
| About | `about.html` | Story, team, and restaurant values |
| Contact | `contact.html` | Table reservation form & location |
| Checkout | `checkout.html` | Order summary and payment flow |
| Dashboard | `dashboard.html` | User profile and order history |

---

## ✨ Features

- **🛒 Shopping Cart** — Add items, adjust quantities, and proceed to checkout
- **❤️ Favourites Drawer** — Save your go-to dishes for quick reordering
- **📅 Table Reservation** — Book a table directly from the contact page
- **🔐 User Authentication** — Sign up / sign in with a profile dropdown
- **📊 Dashboard** — View past orders and manage your account
- **📱 Fully Responsive** — Works seamlessly on mobile, tablet, and desktop
- **⚡ Vanilla JS** — No frameworks; fast, lightweight, and dependency-free

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/RadhikaKapoor383/Costa-Nostra-Premium-Lahori-Cuisine.git
```

### 2. Navigate Into the Project Folder

```bash
cd Costa-Nostra-Premium-Lahori-Cuisine
```

### 3. Open in Your Browser

Since this is a pure HTML/CSS/JS project, no build step or server is needed:

```bash
# Option A — just open the file directly
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux
```

```bash
# Option B — use VS Code Live Server (recommended)
# Install the "Live Server" extension in VS Code, then right-click
# index.html and select "Open with Live Server"
```
